

# SwiftCart AI 🛒✨

**SwiftCart AI** is an AI-powered smart retail platform that connects **customers and retailers** through QR-based shopping, intelligent inventory management, and AI-driven demand forecasting.

🔗 **Live Demo:** [https://swift-cart-ai.vercel.app](https://swift-cart-ai.vercel.app)


## 🚀 Features

### 🛍️ Customer

* QR code product scanning
* Real-time cart management
* Smooth checkout & order confirmation

### 🏪 Retailer

* Business dashboard with key metrics
* Inventory management
* AI-based demand forecasting
* Retail analytics & insights

### ⚙️ Backend

* REST API architecture
* PostgreSQL database (Neon)
* Email notifications via SMTP
* Secure frontend–backend communication


## 🛠️ Tech Stack

* **Frontend:** Next.js 15, React, TypeScript
* **Backend:** Next.js API Routes
* **Database:** PostgreSQL (Neon)
* **ORM:** Prisma
* **Email:** Nodemailer
* **Deployment:** Vercel


## ⚡ Getting Started

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/swiftcart-ai.git
cd swiftcart-ai
```

### 2️⃣ Install Dependencies

```bash
cd backend
npm install

cd ../ai-frontend
npm install
```

### 3️⃣ Setup Database

```bash
cd backend
npx prisma generate
npx prisma db push
```

### 4️⃣ Run the App

Backend

```bash
npm run dev
```

Frontend

```bash
cd ai-frontend
npm run dev
```
